# Welcome to this repo!

This is a little project that I have made and it is very useful for some people.
<br> Lots of people use README.md in their github repos and this is very useful to easily edit and preview markdown files.
<br> There are features like downloading the file as markdown file and html file, you can clear the preview/editor too and I am working on sharing previews.

### Credits:

Only me but I am **very** open to collaborating on this project.

### Use:
The use for this website/project is to edit and preview markdown files.
<br> When you have your preferred edits on the markdown editor, you can click "Download .md" or "Download .html" to save your progress or to share.

### How to download:

#### Download as a ZIP file
- **Navigate** to the main page of the repo
- **Click the green "Code" button** located above the file list
- **Select "Download ZIP"** from the dropdown menu

#### Download the latest Release
- **Navigate** to the main page of the repo
- **Click** on "Releases" and go to the lastest release
- **Click** "Source code (zip)"

#### Download the repo using [git](https://git-scm.com) (for developers)
- **Click** the windows key (if you are on windows)
- **Open** cmd and type in ```git --version```
↳ if there is a **error**, you don't have git then
- **Type** in ```git clone https://github.com/Kanerock17yt/markdown-Previewer MDPreviewerClone``` if there is no error for the last step
